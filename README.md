# python-password-generator
Python password generator with options for digits and special characters

A simple and useful password generator written in Python.

## Description

This program generates strong random passwords based on the user's preferences:
- Password length
- Whether to include numbers
- Whether to include special symbols

## Features

- Custom password length
- Option to include digits
- Option to include special characters
- Simple and clean console interface

## How to run

1. Make sure you have Python installed
2. Download or clone this repository
3. Open terminal in the project folder
4. Run the program:
```  
bash
python main.py
```

## Example

Welcome to the password generator
How long should the password be? 12
Do you need numbers in your password? (yes/no): yes
Do you need special symbols in your password? (yes/no): yes
